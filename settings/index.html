Presence Fusion

Drive Homey’s native presence from several devices — simply. A Homey API key (Presence) is required once.

Homey users

Save a Homey API key in the API tab first. People settings stay locked until then.

Enable Fusion, then open a person to link sources and set rules. Native Homey presence is what Flows use.

Homey API key

Required to write Homey native presence. Apps cannot do this without an API key (Athom limitation).

Homey Web App → Settings → API Keys → New. Check Presence (homey.presence). One key for the whole Homey (all people). Keep it private.

Homey API key

Homey apps can read presence but cannot write it without an elevated API key. Create a key in the Homey Web App (Settings → API Keys), check Presence (homey.presence), then paste it in the API tab. One key covers all people.

  1. Open my.homey.app → Settings → API Keys
  2. New key → check Presence (homey.presence)
  3. Paste the key in the API tab and Save

Location presence

Turn OFF Homey location-based presence for every managed user. Otherwise Homey and Presence Fusion overwrite each other.

Other presence writers

Don’t use Flows (or other apps) that set the same user’s presence. Fusion should be the only writer for managed people — otherwise they overwrite each other.

How it works

  1. Save a Homey API key with Presence
  2. Enable a person
  3. Link devices (phone, Nut, Beacon…)
  4. Homey native presence updates automatically
  5. Use Homey’s built-in Flow cards
